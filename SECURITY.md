# Security policy

Report vulnerabilities privately to **f@nullpunktrec.eu**. Do not open a
public issue for a security report.

You will get an acknowledgement within 7 days. Please include a reproduction
and the affected repository/version. Coordinated disclosure is appreciated;
credit is given unless you prefer otherwise.

Repositories with their own SECURITY.md (e.g. RVND, loomground-solver,
loomground-versum) take precedence over this default.
